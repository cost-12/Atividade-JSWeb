# Atividade JS-Web

Este projeto é uma página web simples criada para demonstrar conceitos fundamentais de JavaScript na manipulação de elementos HTML (DOM). A página é dividida em seções, cada uma focando em uma funcionalidade diferente do JavaScript.

## Descrições

O projeto apresenta exemplos práticos das seguintes manipulações com JavaScript:

### Parte 1: Manipulação de Elementos HTML

- **Modificar Conteúdo de Texto:** Altera o texto de um parágrafo.
- **Modificar Estilo de Elementos:** Muda a cor e o tamanho da fonte de um texto.
- **Adicionar Novos Itens:** Insere novos itens em uma lista dinamicamente.

### Parte 2: Manipulação de Imagens e Divs

- **Alterar Imagens:** Troca a imagem de uma lâmpada (ligada/desligada).
- **Alterar Conteúdo de DIV:** Modifica o conteúdo HTML dentro de um elemento `div`.

### Parte 3: Ocultação e Exibição de Elementos

- **Ocultar e Exibir:** Mostra e esconde elementos de texto e `divs` na página.
- **Alternar Visibilidade:** Um botão que alterna a visibilidade de um container.

### Parte 4: Outros Eventos JavaScript

- Demonstração de 5 eventos comuns do JavaScript com exemplos práticos:

  - `onclick`: Exibe um alerta quando um botão é clicado.
  - `onpaste`: Detecta quando o usuário cola um texto em um campo.
  - `onselect`: Identifica quando um texto é selecionado.
  - `onsearch`: Captura o texto de um campo de busca.
  - `onfocus`: Altera o estilo de um campo quando ele ganha foco.

## Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
